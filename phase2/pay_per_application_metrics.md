# Pay-per-Application Conversion Metrics

## Purpose

This document defines a proposed conversion measurement framework for
the PlaceMux Pay-per-Application flow.

The Day 27 task focuses on establishing the conversion baseline and
making conversion tracking live.

The task brief does not prescribe exact conversion stages or formulas,
so the definitions below are proposed implementation metrics.
