# Questions this dashboard must answer

## Executive questions

1. What is the observed survival rate for the current passenger population?
2. Which passenger class has the weakest observed survival rate?
3. How large is the survival gap between the strongest and weakest class?
4. Which class × sex segment performs worst?
5. Does the observed survival pattern change when class, sex or embarkation port is filtered?

## Decision question

Where should analytical attention be focused based on the weakest observed
passenger segment?

## Interaction principles

The filters exist to test the headline story, not merely to add interactivity.
Every filter combination must return either a valid analysis or a clear empty-state
message without breaking the dashboard.
